# ckb-tx-pool

This crate is a component of [ckb](https://github.com/nervosnetwork/ckb).

CKB Tx-pool stores transactions for CKB's two-step transaction confirmation
mechanism.

Start with the [tx-pool documentation index](docs/README.md). It links the
architecture, pipeline, security history, reviewer guide, implementation
ledger, validation tools, and benchmark protocol. Machine-readable contracts
and inventories remain in this crate root so CI can consume them directly.
